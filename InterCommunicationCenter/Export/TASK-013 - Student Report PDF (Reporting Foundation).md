# TASK-013 - Student Report PDF (Reporting Foundation)

Version: 1.0

Priority: 🔴 HIGH

Estimated Time: 4~6 Days

Owner: DeepSeek

Status: READY

---

# Background

CenterManager MVP is almost complete.

One practical issue remains.

The system is currently shared through Google Drive.

On mobile devices,
opening the application is inconvenient.

Teachers and receptionists need
a quick way to view and share
student information.

PDF is selected because it is

- Universal
- Easy to share
- Easy to preview on phones
- Printable

This task is NOT a generic Export PDF feature.

This task creates the Reporting Foundation
for the entire system.

---

# Objective

Create a reusable ReportService.

Implement the first report

Student Report PDF.

The report must provide a concise,
professional overview of a student.

The PDF should be readable
on both A4 paper and mobile screens.

---

# Architecture

Create

ReportService

        │

        ├── StudentReportGenerator

        ├── (Future) ClassReportGenerator

        ├── (Future) FinanceReportGenerator

        └── (Future) EmployeeReportGenerator

All PDF generation must go through ReportService.

No PDF logic inside StudentService.
