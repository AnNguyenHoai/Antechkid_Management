This is a static review checklist, **not** proof of complete runtime coverage.
Source line numbers refer to that base. Generated by Python AST scanning
services, repositories, database, platform persistence/backup/sync/synchronization
and workflow for calls named commit/flush/execute/executemany/add/delete/persist
and SQLAlchemy bulk methods. Nested functions can appear in enclosing rows;
`execute` may be a read or workflow call, and `flush` may be a file operation.

No central lease/session/epoch fence was found in `database/engine.py`,
`database/session.py` or `repositories/base.py`. Business permission checks,
SQLCipher encryption and the process-local maintenance gate are useful but
independent. Every runtime mutation path must route through a common future
permit boundary; this list must not become a manually maintained allowlist.
