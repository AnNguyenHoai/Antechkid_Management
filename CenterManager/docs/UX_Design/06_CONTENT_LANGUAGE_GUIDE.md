# CENTER DESIGN SYSTEM

# 06. CONTENT LANGUAGE GUIDE

Version: 1.0

Status: Approved

---

# Purpose

This document defines the writing style used throughout CenterManager.

Every page.

Every button.

Every dialog.

Every notification.

Every tooltip.

must use the same language.

Users should feel they are using one product,

not many independently developed modules.

---

# Writing Principles

Writing should be

Clear

Short

Professional

Friendly

Action-oriented

Never

Technical

Verbose

Ambiguous

---

# Product Voice

an experienced education administrator.

Never like

a software engineer.

# Analytics Language

Describe business,

not database.

Good

Enrollment Trend

Average Assessment Score

Attendance Rate

Bad

Student Table Statistics

SQL Result

Data Count

---

# Accessibility

Avoid abbreviations.

Avoid technical jargon.

Use simple language.

Every message should be understandable by non-technical staff.

---

# Translation Ready

Never concatenate sentences.

Bad

"Add " + Student

Good

"Add Student"

All strings should be translation-ready.

---

# Review Checklist

Every text review verifies

✓ Correct terminology

✓ Correct tone

✓ Action-oriented

✓ Consistent verbs

✓ Human-readable

✓ Business language

✓ No technical wording

If any text violates these rules,

it should be rewritten before release.
