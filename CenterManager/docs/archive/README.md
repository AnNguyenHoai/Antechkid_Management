# docs/archive — tài liệu lịch sử

Không dùng các tài liệu ở đây làm nguồn sự thật cho hành vi hiện tại. Xem `../README.md` để biết tài liệu hiện hành.

- `sprint-reports/` — báo cáo triển khai từng sprint/task đã hoàn thành (ADMIN_1_x, CLASS_x, EMPLOYEE_x, STUDENT_x, TEACHER_x, FINANCE_1_x, FINAL_HARDENING_x, EP-RELEASE-01, EP_ARCH_03, PR_F…PR_J, …). Giữ làm bằng chứng lịch sử.
- `legacy/` — tài liệu thiết kế đã bị thay thế: `FINANCE/` (trước Finance Wallet V2), `Software/` (kiến trúc ban đầu), `PROJECT_CONTEXT_sprint0.md`, `CHANGELOG_sprint0.md`, `config.sample.json`.

Chuyển vào đây trong TECH-003 (Issue #562, 2026-11-04) bằng `git mv`, nên `git log --follow` vẫn xem được lịch sử từng file.
