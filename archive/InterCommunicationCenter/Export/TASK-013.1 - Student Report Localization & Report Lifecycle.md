# Background

Student Report PDF has been implemented successfully.

However, after architecture review,
two important product improvements were identified.

Issue 1

The current report is written in English.

CenterManager is designed for Vietnamese training centers.

The default report language must therefore be Vietnamese.

Issue 2

Reports can only be generated manually.

In real operation,
student reports should also be generated automatically
at important learning milestones.

This sprint upgrades the Reporting module
from a simple PDF export feature
to a complete Report Lifecycle.

---

# Objective

Improve Student Report with

✅ Vietnamese localization

✅ Automatic report generation

while preserving the current manual export workflow.
